# 💊 Аптечний агрегатор — Рівне

Локальний вебсервіс для порівняння цін на ліки в аптечних мережах міста Рівне. Ви вводите назву препарату, а сервіс одночасно опитує 7 аптек і показує всі знайдені позиції в одній таблиці. Таблицю можна сортувати за ціною. Для кожної позиції показано, чи є препарат в аптеках Рівного.

Проект не має залежностей: потрібен лише Node.js, `npm install` запускати не треба.

## Можливості

- Паралельний пошук по 7 аптечних мережах, у середньому за 1–3 секунди.
- Ціни та наявність саме по **Рівному**, якщо аптека це підтримує: кількість аптек, адреси філій, діапазон цін.
- Сортування за ціною (▲/▼), посилання на сторінку товару в аптеці.
- Коли аптека не відповіла або перевищила таймаут, решта результатів однаково показується, а помилка виводиться окремою позначкою.
- Світла й темна тема, яка береться з налаштувань системи.

## Підтримувані аптеки

| Аптека | Файл | Джерело даних | Що показується для Рівного |
|---|---|---|---|
| АНЦ / Копійка | [adapters/anc.js](adapters/anc.js) | JSON API anc.ua (місто `69`) | Діапазон цін в аптеках Рівного, кількість упаковок |
| Apteka911 | [adapters/apteka911.js](adapters/apteka911.js) | HTML-сторінка пошуку | Онлайн-ціна «від»; наявність видно на сторінці товару |
| Подорожник | [adapters/podorozhnyk.js](adapters/podorozhnyk.js) | API каталогу (КОАТУУ Рівного в заголовку `x-city`) | Роздрібна ціна, кількість аптек у Рівному |
| Аптека Доброго Дня | [adapters/add.js](adapters/add.js) | Evinent search API | Єдина онлайн-ціна, є / немає в наявності |
| Бажаємо здоров'я | [adapters/aptekanet.js](adapters/aptekanet.js) | API apteka.net.ua: пошук і окремий запит цін по Рівному | Ціна по Рівному, кількість аптек, позначка про е-рецепт |
| Online-Apteka | [adapters/onlineapteka.js](adapters/onlineapteka.js) | MODX AJAX (спершу сесія та hash) | Онлайн-ціна «від» |

Кожен адаптер повертає до 12 позицій (Аптека Доброго Дня — до 10).

## Вимоги

- **Node.js 18 або новіший**, бо потрібні вбудовані `fetch` та `AbortSignal.timeout`. Перевірено на Node.js 24 LTS.
- Інтернет-з'єднання.

Встановити Node.js на Windows:

```powershell
winget install OpenJS.NodeJS.LTS
```

## Запуск

**Windows, найпростіше:** двічі клацніть `start.bat`. Сервер запуститься, і приблизно через 2 секунди браузер сам відкриє сторінку.

**Будь-яка ОС:**

```bash
npm start
# або
node server.js
```

Потім відкрийте **http://localhost:3000**.

Щоб зупинити сервер, натисніть `Ctrl+C` або закрийте вікно консолі.

## Як це працює

1. Користувач вводить запит на сторінці, і браузер робить `GET /api/search?q=...`.
2. [server.js](server.js) паралельно викликає `search()` усіх адаптерів через `Promise.allSettled`. Кожен адаптер має таймаут **15 секунд**.
3. Адаптер звертається до сайту або API аптеки й повертає масив у єдиному форматі.
4. Сервер об'єднує результати, додає до кожного назву аптеки й окремо збирає помилки.
5. Сторінка показує таблицю, відсортовану за ціною. Позиції без ціни опиняються в кінці.

### API

`GET /api/search?q=<запит>`. Запит має містити щонайменше 2 символи, інакше сервер відповість `400`.

```json
{
  "query": "нурофен",
  "tookMs": 1666,
  "count": 82,
  "results": [
    {
      "source": "Подорожник",
      "name": "Нурофен Форте таблетки 400 мг, 12 шт.",
      "price": 126.3,
      "url": "https://podorozhnyk.ua/...",
      "availability": "44 аптек у Рівному"
    }
  ],
  "errors": [
    { "source": "Apteka911", "message": "таймаут" }
  ]
}
```

## Перевірка адаптерів

Сайти аптек іноді змінюють свої API та верстку. Щоб швидко перевірити, які джерела працюють:

```bash
node test-adapters.js            # запит за замовчуванням: «нурофен»
node test-adapters.js парацетамол
```

Для кожної аптеки скрипт виводить кількість знайдених позицій, час відповіді та перші 3 результати. Позиції без назви або ціни він позначає окремо (⚠).

## Як додати нову аптеку

1. Створіть файл `adapters/<назва>.js`:

   ```js
   import { fetchJson } from './util.js';

   export const myPharmacy = {
     name: 'Моя аптека',
     async search(query, { signal }) {
       const data = await fetchJson(`https://.../search?q=${encodeURIComponent(query)}`, { signal });
       return (data.items || []).slice(0, 12).map((p) => ({
         name: p.title,               // рядок
         price: p.price ?? null,      // число або null
         url: p.link || null,         // посилання на товар або null
         availability: 'в наявності', // довільний текст для колонки «Наявність»
       }));
     },
   };
   ```

2. Зареєструйте адаптер у [adapters/index.js](adapters/index.js): додайте імпорт і вставте його в масив `adapters`.
3. Додайте назву аптеки до підзаголовка в [public/index.html](public/index.html).
4. Перевірте результат командою `node test-adapters.js`.

Допоміжні функції з [adapters/util.js](adapters/util.js):

- `fetchText` / `fetchJson` — запити з заголовками звичайного браузера (User-Agent, мова `uk-UA`). Якщо сервер відповів не 2xx, функція кидає помилку.
- `stripTags` — прибирає HTML-теги та декодує entities.
- `parsePrice` — перетворює рядки на кшталт `"1 234,50 грн"` на число `1234.5`.

## Обмеження

- Дані беруться з публічних сайтів і неофіційних API аптек. Якщо сайт змінить API чи верстку, відповідний адаптер може перестати працювати. Решта при цьому працюватимуть і далі.
- Apteka911 та Online-Apteka показують онлайн-ціну «від». Точна наявність у Рівному є на сторінці товару.
- Ціни в аптеці можуть відрізнятися від показаних. Перед покупкою уточнюйте на сайті або телефоном.
- Сервіс призначений для особистого локального використання й працює на порту `3000`. Щоб змінити порт, відредагуйте константу `PORT` у [server.js](server.js).
